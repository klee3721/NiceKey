# NiceKey for Windows

Thư mục này chứa source Windows kế thừa từ OpenKey.

Hiện tại nhánh NiceKey mới ưu tiên rebrand và build macOS. Phần Windows vẫn cần một lượt tách tên project, executable, resource, installer và cấu hình phát hành riêng trước khi dùng làm bản NiceKey chính thức.

## Giấy phép

Mã nguồn tiếp tục phát hành theo GPL-3.0. Xem `LICENSE` ở thư mục gốc và `NOTICE.md` để biết thông tin ghi nhận source gốc.
