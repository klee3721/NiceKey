# NiceKey Sources

Thư mục này chứa source của NiceKey:

- `OpenKey/engine`: engine C++ xử lý gõ tiếng Việt, kế thừa từ OpenKey.
- `OpenKey/macOS`: app macOS, hiện là mục tiêu phát triển chính.
- `OpenKey/win32`: source Windows kế thừa, chưa được rebrand đầy đủ.
- `OpenKey/linux`: khu vực Linux, chưa phát triển trong nhánh NiceKey hiện tại.
